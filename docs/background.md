# Background

Cognitive Harness addresses three problems in autonomous reasoning:

1. **State decay**: Decisions, evidence, and validated knowledge become disconnected from subsequent reasoning.
2. **Underspecified action**: A goal does not determine which knowledge gap to close.
3. **Coupled layers**: Storage leaks into reasoning; reasoning artifacts pollute storage.
