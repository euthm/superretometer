# EPR Completeness — Background

## Source
Einstein, A., Podolsky, B., Rosen, N. (1935). Can Quantum-Mechanical Description of Physical Reality Be Considered Complete? *Physical Review*, 47(10), 777–780.

## Influence on Cognitive Harness
The EPR criterion for "elements of reality" inspired the warrant concept: a knowledge element is only warranted if it can be predicted with certainty without disturbing the system. In Cognitive Harness, this translates to: a conclusion is warranted only if its premises are independently grounded.
