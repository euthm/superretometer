# Harness-of-Harness — Background

## Source
Yan et al. (2026), "Harness-of-Harness" — orchestration framework for AI agent
systems with progressive disclosure and state preservation.

## Influence on Cognitive Harness

The following design aspects are inspired by HoH:

- **Orchestration layer separation** — distinct boundary between storage,
  reasoning, and orchestration layers
- **State preservation** — maintaining reasoning state across trajectories
- **Progressive disclosure** — revealing complexity only when needed

These are general architectural principles, not proprietary implementations.

## Cognitive Harness original contributions

The following are original to Cognitive Harness and not derived from HoH:

- **Structural warrant analysis** — computing epistemic warrant from provenance
  graph topology
- **First-class Threads of Reasoning** — with CAFCR-inspired viewpoint traversal
- **Supersession without history deletion** — succession chains and impact
  propagation
- **Anti-pattern detection** — structural diagnoses from graph analysis
- **Evidence-independence analysis** — tracing evidence to independent provenance
  roots

## Attribution

Conceptual inspiration for orchestration patterns. Cognitive Harness is an
independent work and is not endorsed by the authors of Harness-of-Harness.
