What It Does

  • Computes structural epistemic warrant from provenance graph topology — not keyword matching, not confidence scores
  • Detects structural anti-patterns: circular justification, tautological validation, calibrated-to-conclusion, inert parameters, physically unrealizable claims, unsupported domain transfers
  • Traces evidence to independent provenance roots — evidence count is not independent evidence
  • Manages supersession and impact propagation — when knowledge changes, downstream dependents are flagged
  • Supports Threads of Reasoning with viewpoint traversal (conceptual → functional → realization → application)
  • Provides an MCP transport for integration with agent runtimes

Lineage

Superretometer and the Cognitive Harness specification build on several traditions in reasoning, epistemology and agent orchestration.

Emergent Company

The immediate technical origin of this work lies in research around emergent.memory, the EPF (Emergent Product Framework), and collaboration with Nikolai and Maciej at Emergent Company. Persistent graph memory and structured execution/planning formed the practical starting point from which the Cognitive Harness specification and Superretometer reference engine developed.

Later work is independent. We do not attribute subsequent development to Emergent Company nor imply endorsement.

Gerrit Müller — CAFCR

Müller's A Cognitive Approach for Flexibly Coordinating Reasoning (CAFCR, 2004) introduced Lines of Reasoning and viewpoint-based traversal. The Thread model in Cognitive Harness is a computational instantiation of CAFCR threads, adapted for engineering provenance and warrant analysis.

Müller's later work on CEMA/CESA and viewpoint hopping further informed the structure of explicit engineering reasoning threads.

gaudisite.nl

Einstein, Podolsky & Rosen — 1935

The EPR criterion for "elements of physical reality" inspired the warrant concept: a description that produces plausible results does not guarantee that the elements carrying a conclusion possess independently grounded counterparts.

Cognitive Harness adapts this into an engineering epistemic criterion: a conclusion is warranted only if its premises are independently grounded. This is an analogy, not an implementation of quantum mechanics.

EPR paradox — Wikipedia

Harness-of-Harness

HoH contributed ideas around persistent multi-session agent work, state preservation across reasoning trajectories, progressive disclosure, and long-running orchestration.

Cognitive Harness extends this direction toward explicit engineering reasoning with provenance graphs and structural warrant computation.

Cognitive Harness / Superretometer — Own Contributions

The project's own synthesis and original work:

  • Structural epistemic warrant over provenance graphs
  • Independent provenance-root analysis — evidence count ≠ independent evidence
  • Six structural epistemic anti-patterns derived from graph topology
  • Supersession with transitive impact propagation
  • Automated reassessment when upstream knowledge changes
  • Integration of systems-engineering Threads of Reasoning with provenance/warrant
  • Implementation-independent Cognitive Harness OpenSpec
  • Superretometer reference engine with MCP transport

Superretometer is inspired by and builds on these traditions. It is not affiliated with or endorsed by the original authors or organizations.
