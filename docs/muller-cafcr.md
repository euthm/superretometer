# Müller CAFCR — Background

## Source
Gerrit Müller, *CAFCR: A Multi-view Method for Embedded Systems Architecting; Balancing Genericity and Specificity*, PhD thesis, TU Delft, 2004.

CAFCR = **Customer Objectives, Application, Functional, Conceptual, Realization**.

## Influence on Cognitive Harness
Cognitive Harness adapts the concept of Lines of Reasoning and viewpoint-based reasoning traversal. The Thread model in Cognitive Harness is a computational instantiation of CAFCR threads.
