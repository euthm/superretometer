**Status: release prepared in the repository.** A repository version records the

## Go service

The standalone Go server implements all 11 public MCP tools, with explicit
proposal execution, evidence readback, lifecycle operations and both gate
policies bringing the total to **29 tools**.

- Run the native executable over stdio or Streamable HTTP. The compatible
  `superretometer mcp` command can start an empty graph without a snapshot.
- Retain knowledge objects, evidence, proposals, tensions and history with
  durable `--state` storage, atomic writes and exclusive writer ownership.
  Snapshot import seeds a new state file; completed proposals are idempotent.
- Analyze whole-graph anti-patterns and evaluate four simulation gates and
  seven implementation gates. Filesystem freshness requires repository roots
  explicitly permitted by the operator.
- Use authenticated or proxy-protected HTTP, read-only operation, health
  checks, graceful shutdown and the supplied Docker/Compose configuration.

Proposal execution enforces the existing specification's canonical promotion
requirements, protects identities and succession history, and materializes
accepted tensions. Go analysis is checked against the unchanged Python
conformance and adversarial fixtures; deliberate execution corrections have
separate tests.

## Packaging and compatibility

The Go executable and the `cognitive-harness` Python package are separate
artifacts. The Python package metadata is aligned to **0.10.0**; its runtime
implementation and the normative warrant semantics are unchanged. The Python
wheel contains the Python reference implementation and does **not** include or
install the native Go binary.

Use the [Go build, startup and deployment guide](../../go/README.md) for the
native MCP service. Python checkpoint and test-evidence capture CLIs remain
separate tools. The standalone Go service uses local durable storage; private
Memory/Strategy integrations require a complete graph export for migration.

See [the changelog](../../CHANGELOG.md) for the implementation changes and
subsequent repository updates. Historical v0.9.0 notes continue to describe the
four-tool Go preview delivered at that version.
