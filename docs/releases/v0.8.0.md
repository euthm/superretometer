# v0.8.0 — 2026-11-10

## What changed

Seven structural anti-patterns. Four warrant-bypass defects closed.

### Added

- **`MISSING_INDEPENDENT_VALIDATION` anti-pattern** — fitted parameters without an
  independent test dataset, with unregistered datasets, or with untraceable lineage
  are now diagnosed with the correct label. Previously these were reported as
  `CALIBRATED_TO_CONCLUSION`, which implied circularity that was not present.
- **Unified upstream traversal** (`_trace_upstream`) — a single BFS walks both KOs
  and datasets with shared visited sets. Eliminates inconsistent coverage between
  `_trace_provenance_roots`, `_trace_dataset_roots`, and the circularity check.
- **Provenance source normalisation** — case, surrounding whitespace, and internal
  whitespace runs are canonicalised before root comparison. Two transcriptions of
  the same document now collapse to one root.
- **Evidence validation** — `PHYSICAL_OBSERVATION` KOs with dangling `evidence_ids`
  (IDs that don't resolve to registered evidence records) are no longer treated as
  independently grounded.

### Fixed

- **Multi-hop circularity** — a fitted parameter trained on data two hops from the
  conclusion (via `DERIVED_FROM`, `upstream_ko_ids`, `derived_from_dataset_ids`,
  or a chain through another fitted parameter) is now correctly detected as
  `CALIBRATED_TO_CONCLUSION`. Previously only one-hop was checked.
- **Dataset cycles** — shared visited sets prevent `RecursionError` when datasets
  form a cycle via `derived_from_dataset_ids`.
- **Sourceless dataset** — a fitted parameter with a dataset that has no
  `source_ko_id` now correctly collects its own provenance source as a root,
  matching pre-refactor behaviour.
- **Test dataset circularity** — a test set derived from the conclusion is now
  caught as circular, not just a training set.

### Test coverage

- 11 adversarial warrant-bypass tests (`test_warrant_bypass.py`)
- 6 design-target validation controls (`test_design_target_validation_controls.py`)
  covering direct and multi-hop lineage for each scenario
- **501 passed, 7 skipped**
