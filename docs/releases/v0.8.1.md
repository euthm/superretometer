# Superretometer 0.8.1

When independence data is available, the Memory runtime and packaged MCP server
both return the evidence-to-root mapping in `root_sets` and the reverse mapping
for shared origins in `shared_ancestors`. Applications can trace which findings
share a source. Both entry points preserve their existing empty-result formats.

Install the Python package with `pip install cognitive-harness`. For an existing
installation, see the [update instructions](../local-update.md).
