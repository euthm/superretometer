# Superretometer 0.8.2

Scoped enumeration enables bounded CH analysis on incomplete backends. A
`ScopedManifest` takes an explicit list of KO IDs, verifies completeness within
storage, and supports `list_review_required` and `scan_anti_patterns` without
requiring `enumeration_complete=True` on the backend.

Memory adapter patches prevent crashes on mixed CH/non-CH search results:
non-CH objects receive synthetic provenance, and `_present_ko` guards against
`None` provenance from any adapter.

Evidence chains for CP-010–013 (Rocom BMS connector specs) are traversable but
remain `unwarranted`: evidence KOs reference spec/code/test locations but lack
independent grounding (CI logs, git blob hashes). This is expected — evidence
KOs are provenance references, not evidence content.

Install the Python package with `pip install cognitive-harness`. For an existing
installation, see the [update instructions](../local-update.md).
