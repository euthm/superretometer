# v0.8.3 — Evidence Grounding and Deterministic Explanations

## Changes
- **Evidence lookup fix**: `list_evidence_for_ko` and `get_evidence` now correctly resolve both CH logical IDs and Memory UUIDs for claim matching.
- **Provenance-linked evidence retrieval**: Graph edges preferred over content-level IDs for evidence resolution.
- **Deterministic explanation templates**: Executive, engineering, and audit explanations with 12 tests across 5 CH scenarios.
- **NCM feasibility assessment**: Documented why NCM is not suitable for CH explanation generation (NO-GO).

## Compatibility
- No breaking changes.
- Evidence lookup fix is backward compatible — resolves both old (Memory UUID) and new (CH ID) identifiers.
- Explanation templates are new code, not loaded into default runtime.
