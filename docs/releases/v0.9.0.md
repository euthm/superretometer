# v0.9.0 — Go MCP preview

This release adds an optional Go server for Cognitive Harness graph snapshots.
It serves four read-only MCP tools over stdio or loopback Streamable HTTP.

- `orientation` summarizes the knowledge graph.
- `justification_path` follows upstream evidence and dependencies.
- `impact_set` finds affected downstream objects.
- `check_warrant` evaluates a conclusion and reports its premises, provenance
  roots, and structural diagnoses.

The Python implementation remains the reference. The Go preview builds
separately from the Python package. It reads a local snapshot and has no live
storage adapter, proposal tools, gate evaluation, or graph-wide anti-pattern
scan. See the [Go build and run instructions](../../go/README.md).
